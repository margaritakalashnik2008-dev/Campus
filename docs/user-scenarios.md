1. Гість
Мета: Знайти потрібне оголошення

Початкові умови: Гість відкрив EasyFind, оголошення доступні для перегляду.

Послідовність дій:
1. Відкриває головну сторінку. 
2. Вводить назву товару в пошук. 
3. За потреби вибирає категорію або ціновий діапазон.
4. Відкриває відповідну картку.

Реакція системи:
Система показує список відповідних оголошень і сторінку вибраного оголошення.

Результат:
Знайдено оголошення або показано повідомлення, що результатів немає.

2. Користувач
Мета: Опублікувати оголошення

Початкові умови: Користувач увійшов у свій обліковий запис.

Послідовність дій:
1. Відкриває «Створити оголошення».
2. Заповнює назву, опис, ціну й місто.
3. Обирає категорію та додає фото.
4. Натискає «Опублікувати».

Реакція системи:
Система перевіряє поля та зберігає оголошення; у разі помилки показує підказку

Результат:
Оголошення створено та відображається в особистому кабінеті й каталозі.

3. Модератор
Мета: Опрацювати скаргу

Початкові умови: Модератор увійшов у систему та має доступ до панелі модерації; є скарга.

Послідовність дій:
1. Відкриває список скарг.
2. Переглядає оголошення та причину скарги.
3. Перевіряє відповідність правилам.
4. Схвалює оголошення 

Реакція системи:
Система зберігає рішення та оновлює статус оголошення.

Результат:
Скаргу опрацьовано, статус оголошення оновлено.

4. Адмін
Мета: Змінити роль користувача

Початкові умови: Адміністратор увійшов у систему та має права керування користувачами.

Послідовність дій:
1. Відкриває панель адміністратора.
2. Знаходить користувача.
3. Обирає нову роль.
4. Підтверджує зміну.

Реакція системи:
Система перевіряє права адміністратора й зберігає нову роль.

Результат:
Роль користувача змінено; доступні йому функції відповідають новій ролі.
